## ⚡ Overview

Welcome to the official repository for **Gautam Kumar's Portfolio ("The Digital Workshop")**. Designed and engineered from the ground up as a cinematic, product-first developer showcase, this portfolio communicates technical mastery, practical shipping capability, and clean software architecture.

### ✨ Highlights

- 🖥️ **Interactive 3D Digital Workspace**: Three.js WebGL command center with mouse parallax, floating architecture shards, and ambient starfields.
- 🌌 **3D Technical Constellation**: Interactive raycasted skill galaxy linking core tools (React, Node.js, Python, PostgreSQL, LLMs) to actual shipped products with dynamic laser conduits.
- 🧲 **Tactile UX Motion**: Spring-physics magnetic buttons, custom 60fps lerp cursor with `"VIEW"` expansion, 3D card tilt perspective, and sub-800ms GK monogram loading telemetry.
- 📱 **Mobile & Tablet Optimized**: Ultra-responsive layout scaling seamlessly from 320px mobile screens to 4K ultra-wide monitors.
- ♿ **Accessibility & Reduced Motion**: WCAG AA compliant with `:focus-visible` neon rings, skip-to-content shortcut, and automatic bypass for `prefers-reduced-motion: reduce`.
- 🔍 **SEO & Search Engines**: Comprehensive Open Graph, Twitter cards, JSON-LD structured schemas, `robots.txt`, and `sitemap.xml`.

## 🏗️ Technical Stack

- **Core & Runtime**: React 19, TypeScript, Vite 8
- **3D Graphics & WebGL**: Three.js, Canvas 2D Dynamic Textures
- **Styling & Layout**: Vanilla CSS with strict HSL Design Tokens, Glassmorphism, and Spring Curves (`cubic-bezier(0.16, 1, 0.3, 1)`)
- **Typography**: Syne (Headings), Geist / Inter (Body), JetBrains Mono (Telemetry & Code)
- **Icons & Effects**: Lucide React, Canvas Confetti
- **Performance**: Rollup manual chunking splitting Three.js, React vendor, and UI components into independent cacheable assets.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18+ recommended)
- [pnpm](https://pnpm.io/) or [npm](https://www.npmjs.com/)

### Installation

```bash
# Clone the repository
git clone https://github.com/Gautam-kumar01/my-portfolio.git

# Navigate into the project folder
cd my-portfolio

# Install dependencies
pnpm install
# or
npm install
```

### Development Server

```bash
pnpm dev
# or
npm run dev
```

Visit `http://localhost:5173` to explore the live development server.

### Production Build & Typecheck

```bash
# Typecheck
pnpm check

# Build production bundle
pnpm build

# Preview production build locally
pnpm preview
```
